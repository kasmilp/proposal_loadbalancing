## Cara Pakai

1. Buka `00_INDEX/Peta_Pembahasan.md` untuk melihat folder yang relevan dengan subbab Bab I–II.
2. Buka `00_INDEX/Daftar_Jurnal.md` untuk melihat daftar berkas, tahun, status, dan catatan.
3. Untuk sitasi, prioritaskan versi **utama** (tanpa `annotated`). Versi `annotated` adalah salinan dengan anotasi.
4. Berkas `.htm` adalah full-text HTML; konversi ke PDF bila diperlukan.
5. `LITERATUR_SCOPUS_INDEXED.docx` dan `peryataan ALQI.pdf` adalah dokumen kerja, bukan artikel jurnal.
6. `hysteresis.pdf` adalah artikel fisika tentang histeresis dinamis; gunakan sebagai konsep dasar, bukan bukti empiris jaringan.

## Catatan Git

Ukuran koleksi ini besar (±264 MB). Jika akan di-commit ke Git, pertimbangkan **Git LFS** atau tambahkan folder ini ke `.gitignore` dan simpan koleksi di penyimpanan eksternal. Jangan commit berkas PDF berhak cipta ke repositori publik tanpa memeriksa lisensinya.
